Simple potion helper for the [Simonrim][1] / [Apothecary][2] skyrim mod.

Online version at https://marcelboisson.github.io/simonrim-pots-helper

3 views:

<dl>
<dt>Brew</dt>
<dd>Select multiple ingredients and see what potions can be brewed</dd>

<dt>Effects</dt>
<dd>Select one effect and see what ingredients provide it</dd>

<dt>Find</dt>
<dd>Select multiple effects and see what combination of ingredients (if any) provide it</dd>
